## Getting Started

The API is hosted at `https://api1.intelltracking.com` and follows standard RESTful principles. You can interact with the API using any HTTP client.

If you want to use Postman or a similar client, or you want to auto-generate code-stubs, you can download the OpenAPI 3.0 specification here:

[Download OpenAPI 3.0 Specification](https://storage.googleapis.com/intelltracking-api-files/api.openapi.json)

<Tip>You can also explore our API using this documentation platform. Please use the sidebar to find the endpoints and their details.</Tip>

## Authentication

The API uses a standard `Bearer Token` authentication scheme. You will need to include your API key in the `Authorization` header of each request.
